Your books, places, highlights, notes, bookmarks, details and stats are kept in a private folder of your own Google Drive, and any device signed in to the same reader has them. Nothing goes anywhere else.

Set up
How to get a client ID (once, about ten minutes)
  1. Go to console.cloud.google.com, sign in, and create a project (any name).
  2. Left menu → APIs & Services → Library. Search Google Drive API and enable it.
  3. APIs & Services → OAuth consent screen. Choose External, give the app a name, add your email as the support and developer contact, save. Under Test users, add your own Google account.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID. Type Web application. Under Authorized JavaScript origins add the exact address you open the reader at, shown above.
  5. Copy the Client ID it shows and paste it above, on every device.
Where to put the file so both devices can open it

Google will only sign in a page served from a web address, not a file opened from disk. The simplest free home is a private GitHub Pages site or any static host; or on your computer, a one-line local server (python -m http.server in the folder, then open http://localhost:8000/cadence.html). Your phone needs a web address too, so hosting is the practical answer; the books themselves never pass through the host — only this one file does.
